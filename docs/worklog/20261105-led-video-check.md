# 2026-11-05: 全灯・全消灯の動画と通常デモログ確認

## 証拠

- [実機動画（約 2.2 秒）](../assets/breadboard-leds-on-off.mp4)
- 動画ファイルの記録サイズ: 1440 × 1080

## 観測したこと

1. 8 個の LED が同時に点灯している。
2. 8 個すべてが消灯する。
3. その後、8 個が再び同時に点灯する。

配線後に LED が点灯・消灯することは動画から確認できる。通常デモの全灯・全消灯部分と整合する動きだが、動画にシリアルログが含まれていないため、この動画単独では実行モードや送信値を特定できない。

## 通常デモの書き込みとログ

USB ケーブルを接続し直した後、同じ日に現在のコードを実機で確認した。

1. `/dev/ttyACM0` として Espressif USB JTAG/serial debug unit を認識した。
2. `mix atomvm.esp32.info` で ESP32-C5 と AtomVM `v0.7.0-beta.0-19-ga1069573` を確認した。
3. クリーンビルド、AtomVM 命令チェック、AVM 作成が成功した。
4. `mix atomvm.esp32.flash --port /dev/ttyACM0` が成功し、書き込み後のハッシュ検証も成功した。
5. シリアルログで `ready,demo` に続き、次の 1 周分と次周の開始を確認した。

```text
255 → 0 → 1 → 2 → 4 → 8 → 16 → 32 → 64 → 128
    → 64 → 32 → 16 → 8 → 4 → 2 → 1
    → 0 → 85 → 170 → 255 → 0 → 255 → 0 → 1 → ...
```

`gpio_error` と `write_error` は出ていない。これにより通常デモのソフトウェア出力は実機上で確認できた。ただし、動画とシリアルログは別々に取得したため、個々のログ行と LED を同時には照合していない。

## この動画だけでは確認できないこと

- `all_off` 診断モードの `0x00` と全消灯を同時に観察すること
- `0x01` が QA、`0x80` が QH の 1 灯だけを点灯すること
- QA → QH → QA の順で往復すること
- `0x55` と `0xAA` が交互に表示されること
- 電源を入れ直した後も同じ動作を安定して繰り返すこと

これらは診断モードのシリアルログと LED を同時に観察して確認する。

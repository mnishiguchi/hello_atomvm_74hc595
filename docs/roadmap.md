# ロードマップと検証状況

このリポジトリの目標は **XIAO ESP32-C5 + AtomVM + SN74HC595N で 8 個の LED を再現性よく制御すること**です。

## 2026-11-05 時点

- [x] ホストの単体テストが成功（10 tests, 0 failures）
- [x] XIAO ESP32-C5 を検出し、AtomVM アプリを書き込めた
- [x] `0xFF` を送ったときに 8 個の LED が点灯した（写真あり）
- [x] 短い動画で 8 個の LED が同時に消灯・再点灯することを確認
- [x] 通常デモ 1 周分の値と、次の周回開始をシリアルログで確認
- [x] SRCLR (pin 10) → 3V3 の接続漏れが疑われる点を配線ガイドへ反映
- [ ] `0x00` で 8 個とも消灯することを実機で確認
- [ ] `0x01` が QA、`0x80` が QH の 1 灯のみを点灯することを実機で確認
- [ ] 通常デモの往復点灯と交互点灯を目視で確認
- [ ] 電源の再投入後も安定して動くことを確認

動画だけでは実行中の値を特定できないため、`0x00` の実機確認は診断モードのログと合わせて別途行います。全灯・全消灯の成功だけでも、QA〜QH と個々の LED の対応が正しいとは断定できません。

## 完了の条件

1. ホストテストとフォーマットチェックが成功する。
2. `all_on`、`all_off`、`qa`、`qh` が実機で期待どおりに動く。
